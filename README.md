<br>

- 🧭 **Every story I tell about my work starts with curiosity**, with the habit of wondering what really happens behind the screen, how a single request travels across a network, how a server decides who is allowed in, and where a clever attacker might find a way through, and that curiosity is what carried me from general computing into **cybersecurity, system engineering, networking and IT infrastructure**.

- 🎓 **My foundation was built step by step**, beginning with Diplomas in ICT and English and growing into a **Pearson BTEC Level 5 HND in Computing (Merit) at ESOFT Metro Campus**, where I learned to connect theory with the practical, hands-on way real systems are designed, broken and repaired.

- 🛡️ **Security is where my mind naturally goes first**, so I spend my time on vulnerability assessments, web and API security testing, system hardening, network security and SIEM log analysis, always trying to see a system the way a defender needs to and the way an attacker would.

- 🖧 **I enjoy the machinery that keeps everything running**, from Linux and Windows administration to Active Directory, Group Policy, DNS, DHCP, VPNs, VLANs, NAT and virtualization, and from IPv4/IPv6 subnetting to Cisco Packet Tracer labs where a tangled network slowly becomes a clean, working design.

- 💻 **Code is the tool I use to turn ideas into something real**, whether that means automating a repetitive admin task with Python, Bash or PowerShell, or building full applications with Java, Spring Boot, Next.js, Node.js, REST APIs and database-driven back ends.

- 🔧 **I learn best by building**, which is why my projects include Linux server hardening tools, SIEM log analysis utilities, subnetting calculators, system administration tools and business applications, each one a small experiment that taught me something I could not have learned from a book alone.

- 📜 **Learning never stops for me**, and it shows in the journey behind these badges: Cisco CCNA, CyberOps Associate and DevNet Associate, ISC2 CC, Fortinet FCA, ISO/IEC 27001 and 20000, API security and web application penetration testing certifications, plus Google, IBM and Linux Foundation training and a long list of cybersecurity job simulations.

- 🎯 **The road ahead is clear to me**: I want to grow into **SOC operations, infrastructure security and IT systems administration**, where I can defend real environments, sharpen my practical skills every day and keep turning what I learn into safer, more reliable systems.

- 🤝 **I'm always open to a good conversation**, so if you enjoy talking about security, networks, Linux or building useful tools, feel free to connect with me and let's learn something together.
